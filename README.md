# Местечко

Онлайн-запись для малого бизнеса услуг: салонов, барбершопов, клиник, автосервисов.
Клиент записывается в Telegram Mini App или в виджете на сайте заведения, бот в Telegram и MAX
напоминает о визите и даёт перенести или отменить запись, владелец ведёт в веб-кабинете
расписание, команду, услуги, клиентов, лояльность и отчёты.
«Есть местечко?» — свободное окно, с которого начинается каждая запись.

> Это демо-версия: всё работает по-настоящему, данные вымышленные.

## Запуск локально

Нужны Node 24.11+, pnpm 10, Docker с Compose.

```bash
pnpm install
pnpm env:init          # создаёт .env: локальные адреса и случайные секреты
pnpm infra:up          # PostgreSQL и Redis в Docker
pnpm db:setup          # роль приложения, миграции, демо-данные
pnpm dev:api           # API, фоновые задачи и боты (роли api, worker, bot)
pnpm dev:miniapp       # Mini App
pnpm dev:cabinet       # кабинет
pnpm dev:widget        # виджет записи и демо-сайт салона
pnpm dev:landing       # сайт продукта
```

| Кабинет                                 | http://127.0.0.1:46220                                                  |
| Mini App (вне Telegram — демо-эмулятор) | http://127.0.0.1:46230                                                  |

Сборка для продакшена: `pnpm build`, просмотр собранных фронтендов — `pnpm --filter @mestechko/cabinet preview` (46221), `pnpm --filter @mestechko/miniapp preview` (46231), `pnpm --filter @mestechko/widget preview` (46241) и `pnpm --filter @mestechko/landing preview` (46251). Продакшен-стек целиком (Docker, Caddy с TLS, бэкапы) — `docker-compose.prod.yml`, см. [docs/deploy.md](docs/deploy.md).

Остановить инфраструктуру: `pnpm infra:stop`.

### Стенд одной командой

`pnpm stand` поднимает PostgreSQL и Redis, применяет миграции и запускает API (вместе с
фоновыми задачами, ботом Telegram в режиме long polling и ботом MAX), кабинет, Mini App,
виджет и сайт продукта на их портах. Процессы отвязаны от терминала и продолжают работать
после его закрытия, логи — в `.run/logs/`. `pnpm stand --reset` перед запуском возвращает
демо-данные к исходным, `pnpm stand:status` показывает, что запущено и отвечает,
`pnpm stand:stop` останавливает всё, включая контейнеры.

## Языки

Все части продукта говорят по-русски и по-английски. Язык человека выбирается так: его
сохранённый выбор, иначе язык, который сообщает Telegram (`language_code`) или браузер, иначе
английский. Переключатель есть на странице входа и в меню аккаунта кабинета, в шапке сайта
продукта и виджета, в «Настройках» Mini App (пункт меню Telegram; выбор хранится на сервере,
и бот пишет на том же языке). Демо-входы на английском открывают англоязычную студию
Marigold Studio, на русском — российские заведения. MAX — канал российского рынка: в
английском интерфейсе раздела «Эмулятор MAX» и упоминаний MAX нет. Деньги — в валюте
заведения, даты и время — по языку читателя в часовом поясе филиала. Подробности — в
[docs/architecture.md](docs/architecture.md#языки).

## Демо-данные

`pnpm demo:reset` возвращает демо-бизнесы к состоянию seed: удаляет их вместе с записями,
клиентами и сообщениями и создаёт заново. В развёртывании то же делает каждую ночь сервис
`demo-reset` (`pnpm demo:schedule`: планировщик BullMQ, `DEMO_RESET_CRON` в
`DEMO_RESET_TIMEZONE`, по умолчанию 04:00 по Москве). Скриншоты снимаются на отдельной базе `mestechko_screenshots`, которую
`pnpm screenshots` каждый раз создаёт с нуля, — рабочая демо-база не меняется. Что внутри
демо-данных и почему телефоны вида «+7 0XX …», — в [docs/demo-data.md](docs/demo-data.md).

## Предоплата и тестовая касса

Предоплату задаёт правило вертикали или бизнеса (доля от цены, время на оплату) и, при
необходимости, своя доля у отдельной услуги — у «Сирени» это окрашивание (30 %), у «Эмали» —
отбеливание (20 %). Запись с предоплатой держит время, пока клиент платит; не оплатил вовремя
или отказался от оплаты — время освобождается.

Платёжный провайдер подключён через порт `PaymentProvider`. В демо это «Тестовая касса» —
эмулятор провайдера внутри API (`TEST_PAY_EMULATOR_ENABLED=true`): API провайдера под
`/test-pay/api`, страница оплаты `/test-pay/checkout/:id` с кнопками «Оплатить» и
«Отказаться от оплаты», подписанные HMAC вебхуки на `/v1/payments/webhooks/test`. Повторный
вебхук ничего не меняет. При отмене возвращается предоплата: всегда, если отменяет заведение,
и если клиент отменил, пока онлайн-изменения открыты. Ключи кассы выдаёт `pnpm env:init`.

## Виджет для сайта

Код для вставки — в кабинете: «Настройки → Виджет для сайта» (в блоке страницы или кнопкой
с окном, светлая, тёмная или системная тема):

```html
<div data-mestechko-widget></div>
<script src="https://…/widget.js" data-mestechko data-business="siren" async></script>
```

Форма живёт в iframe, а кнопка и окно скрипта — в Shadow DOM: стили сайта и виджета не
смешиваются. Пример — вымышленный сайт салона «Сирень»: `/demo/siren.html` на адресе виджета,
на английском — сайт студии Marigold: `/demo/marigold.html`.

## Telegram-бот

Токен бота — в `.env`, ключ `TELEGRAM_BOT_TOKEN` (файл в `.gitignore`), имя бота —
`TELEGRAM_BOT_USERNAME`. Без токена Mini App работает на демо-подписи, бота нет.

- **Обновления.** В разработке процесс с ролью `bot` получает их long polling. В продакшене:
  `TELEGRAM_UPDATES_MODE=webhook`, `TELEGRAM_WEBHOOK_URL=https://…/v1/telegram/webhook` и
  `TELEGRAM_WEBHOOK_SECRET`; процесс с ролью `bot` регистрирует webhook при старте.
- **Профиль бота.** `pnpm bot:setup` задаёт команды, описание и короткое описание из
  переводов (`apps/api/src/locales/<язык>/bot.json`) на каждом языке, по умолчанию — на английском;
  аватар и имя не трогает. Текст menu button у Telegram один на всех — английский. Menu button с Mini App
  появится, когда задан `MINIAPP_PUBLIC_URL` (https), до этого меню показывает команды.
- **Проверка на живом боте.** Запустите API (`pnpm dev:api`), откройте бота в Telegram и
  нажмите «Запустить». `pnpm bot:check booking` запишет вас в демо-салон через обычный сценарий
  записи (`--in-hours 2.2` — напоминание за 2 часа придёт минут через десять);
  `pnpm bot:check waitlist` поставит в лист ожидания и пришлёт предложение свободного времени.
- **Кому бот пишет.** Только тем, кто нажал «Запустить» (`/start`). Напоминания приходят
  за 24 и за 2 часа до визита, во втором — кнопка «Приду». Перенос и отмена — кнопками,
  пока до визита больше срока, заданного вертикалью (у салона 2 часа).

## MAX

Реального бота MAX нет: в демо API включает эмулятор MAX Bot API (`MAX_EMULATOR_ENABLED=true`,
`MAX_API_BASE_URL=http://127.0.0.1:46210/max-emulator`, `MAX_BOT_TOKEN` — любой секрет, его
выдаёт `pnpm env:init`). Бот работает с эмулятором через тот же адаптер, что и с настоящим MAX.
В кабинете раздел «Эмулятор MAX» показывает переписку клиентов с ботом и даёт нажимать кнопки
и писать боту от имени клиента. У каждого демо-бизнеса восемь клиентов «пользуются MAX».

## Качество

```bash
pnpm gate              # размеры файлов и папок, токены, переводы, формат, линтер, типы, контракты, unit-тесты
pnpm test:integration  # PostgreSQL и Redis: брони, изоляция тенантов, ограничения, миграции,
                       # бот на тестовом Bot API: напоминания, явка, перенос, отмена, лист ожидания
pnpm screenshots       # скриншоты сайта, Mini App, кабинета и виджета: 390/768/1280 во всех
                       # темах на чистой базе из seed (своя БД, API, превью)
pnpm media:landing     # экраны и ролики для сайта продукта на чистой базе (--locale ru|en)
pnpm media:film        # фильм о продукте 1920×1080 и 1080×1920 в docs/case/video
```

Нагрузочный тест — k6 из Docker-образа `grafana/k6` по продакшен-стеку, сценарий
`tooling/load/booking-load.js`, результаты и запуск — в [docs/performance.md](docs/performance.md).
